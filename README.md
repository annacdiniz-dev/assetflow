# AssetFlow

Sistema web para gerenciamento de patrimônio, desenvolvido com foco no controle de ativos, empréstimos e histórico de movimentações.

## Status

🚧 Projeto em desenvolvimento.

## Objetivo

Desenvolver uma aplicação web que permita organizar e acompanhar o ciclo de vida dos patrimônios de uma organização, aplicando conceitos de desenvolvimento web, banco de dados e boas práticas de engenharia de software.
